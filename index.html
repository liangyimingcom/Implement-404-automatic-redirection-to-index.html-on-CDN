功能说明

本系统使用 AWS Lambda@Edge 技术实现了智能的 404 错误处理机制。当用户访问 CloudFront 分配中不存在的资源时，系统会自动将用户重定向到主页（/index.php 或 /index.html），而不是显示错误页面。

技术特点

  • 🚀 无缝重定向：用户体验流畅，无需看到错误信息
  • 🌐 全球边缘部署：Lambda@Edge 在全球 CloudFront 边缘位置执行，响应迅速
  • 🔧 灵活配置：可以轻松修改重定向目标和规则
  • 📊 完整日志：所有重定向操作都记录在 CloudWatch 日志中
  • 🔒 安全可靠：基于 AWS 原生服务，安全性有保障

工作原理

  1. 用户请求一个不存在的资源
  2. 源服务器返回 404 状态码
  3. Lambda@Edge 函数拦截这个响应
  4. 函数将 404 转换为 302 重定向
  5. 浏览器自动跳转到 /index.php
  6. 用户看到主页内容而不是错误信息

Lambda@Edge 函数代码示例

exports.handler = async (event) => {
    const response = event.Records[0].cf.response;
    if (response.status === '404') {
        response.status = '302';
        response.statusDescription = 'Found';
        response.headers.location = [{ key: 'Location', value: '/index.php' }];
    }
    return response;
};
